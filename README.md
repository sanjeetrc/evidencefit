# EvidenceFit

Evidence-based exercise and protein companion for 60+ users. Installable, works offline, and keeps all data on the phone.

- Use: open the published URL in Chrome on Android → menu → **Install app**.
- Develop: `npm ci`, `npm run dev`
- Check: `npm run typecheck && npm test && npm run build && npm run e2e`
- Release: push to `main`; GitHub Actions tests, builds and publishes to GitHub Pages.

Delivery record, decisions, verification evidence and runbook: [docs/delivery/README.md](docs/delivery/README.md).
